# Página de links — Meliponário Santa Rosa

Página estática responsiva, publicada via GitHub Pages a partir do repositório `msr-link`.

## Estrutura (raiz do repositório)

- `index.html` — a página.
- `assets/logo-msr.svg` — logotipo oficial em vetor (fundo transparente), vindo dos ativos do brandbook.

## Publicar / atualizar

1. Os arquivos devem ficar na **raiz** do repositório (não dentro de subpastas).
2. Em **Settings → Pages**, em **Build and deployment**, usar **Deploy from a branch**: branch `main`, pasta `/(root)`.
3. O endereço público é exibido pelo GitHub nessa mesma tela após a publicação.
