# Página de links — Meliponário Santa Rosa

Página estática responsiva, preparada para GitHub Pages.

## Publicar no GitHub

1. Crie um repositório no GitHub, por exemplo `msr-links`.
2. Envie `index.html`, `README.md` e a pasta `assets` (com `logo-msr.jpg`) para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde o GitHub mostrar o endereço público da página.

## Atualizar o logotipo

O arquivo `assets/logo-msr.jpg` é uma extração do logotipo presente no manual de identidade da MSR, recortada para uso nesta página. Se tiver uma versão oficial em alta resolução ou com fundo transparente, substitua esse arquivo pelo novo e mantenha o nome `logo-msr.jpg` (ou ajuste o caminho no `index.html`).
